## 2. Hors programme (non exigé, non évalué)
- Propriétés algébriques des racines carrées (√a×√b = √(ab), √(a/b), simplification de √12 en 2√3) : note officielle « aucune propriété algébrique des racines carrées n'est attendue ». Le chapitre n'utilise que la définition, (√a)² = a, √(a²) = a pour a ≥ 0, et la croissance pour encadrer.
- Exposants non entiers ; racines n-ièmes.
- Le contre-exemple √(a+b) ≠ √a + √b est traité comme **erreur à éviter**, non comme propriété.

## 3. Définitions retenues
- aⁿ (n ≥ 1) produit de n facteurs ; a⁰ = 1 et a⁻ⁿ = 1/aⁿ pour a ≠ 0.
- Notation scientifique : a × 10ⁿ, 1 ≤ a < 10, n entier relatif.
- √a (a ≥ 0) : nombre positif dont le carré vaut a.
- Valeur exacte / valeur approchée (symbole ≈).
- Rationnel a/b ; inverse.

## 4. Méthodes
Priorités avec fractions ; division = multiplication par l'inverse ; règles des exposants retrouvées en comptant les facteurs ; séparer nombres et puissances de 10 puis réajuster ; ℓ² = a ⇒ ℓ = √a (longueur positive), arrondi en fin de calcul.

## 5. Erreurs typiques (diagnostiquées dans les exercices)
Addition des dénominateurs ; division sans inverser ; a⁻ⁿ lu comme −aⁿ ; aⁿ lu comme a×n ; exposants multipliés au lieu d'additionnés ; −aⁿ vs (−a)ⁿ ; √(a+b) = √a + √b ; égalité au lieu de ≈ ; mantisse hors de [1 ; 10[ ; arrondi intermédiaire (périmètre calculé avec le côté arrondi) ; troncature au lieu d'arrondi.
